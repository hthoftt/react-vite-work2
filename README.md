# 借我穿一下 | 二手潮流服飾共享平台

二手潮流服飾共享平台,包含前台購物流程與後台管理系統,串接 API 取得 token 驗證,可管理商品與訂單。

[線上 Demo](https://hthoftt.github.io/react-vite-work2/)

[後台 Demo](https://hthoftt.github.io/react-vite-work2/#/login)

## 功能
- 前台:首頁、起源、顧客回饋、商品列表、購物車
- 後台登入:串接 API 取得 token 進行驗證
- 商品管理:可新增、編輯、刪除
- 訂單管理:可新增、編輯、刪除
- 部分介面使用 Bootstrap 模板
- 商品資料透過 API 取得
- 表單驗證使用 React Hook Form
